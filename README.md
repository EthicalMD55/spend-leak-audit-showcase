# Spend Leak Audit — Showcase

A portfolio demonstration of a deterministic SaaS spend-audit system designed to identify potential software-spend waste from structured billing and usage data.

## What this demonstrates

- Vendor-spend analysis
- Usage and license review signals
- Duplicate/overlap safeguards
- Currency mismatch detection
- Traceable findings
- Human-verification-first recommendations
- Automated Markdown/HTML client reporting

## Demo

This repository contains a **fictional pilot report** generated from synthetic data.

**Demo input:** fictional/synthetic data  
**Total spend analyzed:** $183,348  
**Findings:** 66  
**Potential reduction identified:** $48,324  
**Potential-saving findings:** 7

These figures are **not real customer savings** and are not presented as guaranteed outcomes.

## Trust model

The underlying system is designed to separate:

**Data signal → Potential reduction → Human verification**

The system does not claim guaranteed savings or automatically cancel services.
